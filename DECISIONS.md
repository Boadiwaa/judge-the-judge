- **D-03** Omission matching extended: besides the spec rule (judge evidence or span overlaps the omitted original text), a finding also matches if its `transcript_evidence` overlaps (partial ratio ≥ 80) the text of one of the seeded error's `evidence_turns`. · A judge quoting the patient verbatim ("Penicillin. I come out in a rash.") scores only 56 against the note-style original text and would be scored as a miss under the literal rule, which would undercount judges. · `python scripts/compute_metrics.py --strict-spec` writes `*_strict.json` with the spec-literal rule; both are reported. **Approved by Paulina on 2026-10-28, before any judge run (pre-registered). The extended rule is primary; the spec-literal rule is reported as a sensitivity analysis.**
- **D-04** A note with no judge output (parse failure after one retry) counts all its seeded errors as missed, and the failure count is reported per judge. · Conservative; a judge that cannot produce valid output has not detected anything. · Change the `no_output` branch in `src/jtj/metrics.py`.
- **D-05** Spans shorter than 4 characters after normalisation never match. · Stops "OD" or "a" matching anything. · `MIN_LEN` in `src/jtj/match.py`.
- **D-06** Paired McNemar comparisons are computed on High + Very high errors (the primary endpoint population) and on all errors; Holm is applied within each scope across the two comparisons. · The spec says "on the same seeded errors" without naming the subset; doing both is transparent. · Edit `compute_all` comparisons block.
- **D-07** Severity agreement (weighted κ, Gwet AC2) uses judge vs answer-key *severity* (1–5) on detected errors, with ordinal weights for AC2 and quadratic for κ. · Spec names "severity agreement"; tier agreement can be added. · `metrics.py` severity block.
- **D-08** Gwet AC1/AC2 implemented per Gwet (2014); agrees with `irrCAC` 0.4.4 to 1e-4 on identity, quadratic, ordinal and linear weights with missing ratings (tests/test_stats.py). · Spec cross-check requirement. · n/a
